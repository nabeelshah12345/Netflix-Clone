# 🎬 Netflix Clone

A responsive **Netflix Landing Page Clone** built using **HTML5** and **CSS3**. This project recreates the look and feel of Netflix's homepage while focusing on responsive web design, clean layouts, and modern CSS styling techniques.

---

# 📖 Overview

This project is a frontend clone of the Netflix landing page created for learning and practicing HTML and CSS. The goal was to improve UI development skills by replicating a real-world website with attention to layout, typography, spacing, colors, and responsiveness.

---

# ✨ Features

* 🎥 Netflix-inspired landing page
* 📱 Fully responsive design
* 🎨 Modern and clean user interface
* 🖼️ Hero section with background image
* 📺 Multiple content sections
* ❓ Frequently Asked Questions (FAQ) section
* 🚀 Smooth layout and professional styling
* 💻 Mobile, tablet, and desktop compatible
